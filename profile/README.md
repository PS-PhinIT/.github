# PhinIT Hub
## Powered by [phinit.de](https://www.phinit.de) & [psscripts.de](https://www.psscripts.de)

### Welcome to the central repository hub of **PhinIT**.  
Here you will find a broad spectrum of open-source projects, administrative tools, and production-tested automation solutions for modern IT environments — spanning web application development, cloud governance, and enterprise infrastructure management.

👉 **[Explore All Repositories](https://github.com/orgs/PS-PhinIT/repositories)**

---

## 🛠️ What You Will Find Here

- **🌐 Web Development & CMS Ecosystem (PHP):**  
  Self-hosted, modular, and GDPR-compliant business web solutions, including content management engines, custom plugins, and responsive frontend themes.
- **☁️ Microsoft 365, Hybrid Exchange & Cloud Governance:**  
  Automation and management solutions for Exchange Online, hybrid mail flow, proxy address handling, direct on-premises AD Exchange attribute management without an Exchange server, tenant security checks, and licensing audits.
- **🏢 Active Directory & Identity Management:**  
  WPF/XAML-driven desktop GUIs and command-line automation for streamlined user onboarding, delegated password resets, group lifecycle administration, and permission management.
- **🖥️ Enterprise Systems, Virtualization & RMM:**  
  Tools for Hyper-V management, Windows DNS administration, server maintenance, file system operations, certificate lifecycle automation, and custom monitoring/remediation tasks for RMM platforms (such as NinjaOne).
- **🛡️ Auditing, Reporting & Infrastructure Analysis:**  
  Comprehensive auditing suites for Active Directory, NTFS and share permissions, client health, and server baselines.
- **🐧 Linux Operations & Reusable Script Frameworks:**  
  Shell scripts, system configuration templates, modular PowerShell libraries, and development boilerplates for day-to-day operations.

---

## 🛠️ Themenschwerpunkte im Überblick

- **🌐 Webentwicklung & CMS-Ökosystem (PHP):**  
  Modulare, DSGVO-konforme Business-Lösungen für das Self-Hosting – von Content-Management-Systemen über maßgeschneiderte Plugins bis hin zu responsiven Themes.
- **☁️ Microsoft 365, Hybrid Exchange & Cloud Governance:**  
  Werkzeuge für Exchange Online, hybriden Mailflow, Proxy-Adress-Pflege, direkte Attributverwaltung im Active Directory ohne lokalen Exchange Server sowie Skripte für Tenant-Sicherheitsprüfungen und Lizenzübersichten.
- **🏢 Active Directory & Identity Management:**  
  WPF/XAML-gestützte Admin-Tools mit intuitiver GUI sowie CLI-Lösungen für automatisiertes Benutzer-Onboarding, sicheren Passwort-Reset im Helpdesk und Gruppen- und Verzeichnisverwaltung.
- **🖥️ Enterprise-Infrastruktur, Virtualisierung & RMM:**  
  Lösungen für Hyper-V-Cluster, Windows-DNS-Pflege, Server- und Storage-Wartung, Skript-Zertifikate sowie Überwachungs- und Wartungsskripte für RMM-Systeme (wie NinjaOne).
- **🛡️ Auditing, Reporting & Sicherheitsanalyse:**  
  Ganzheitliche Reporting- und Prüf-Suiten zur Analyse von Active-Directory-Umgebungen, NTFS-/Freigabeberechtigungen, Server-Zuständen und Client-Inventaren.
- **🐧 Linux-Administration & Modul-Baukästen:**  
  Shell-Skripte für Linux-Server, wiederverwendbare PowerShell-Modulsammlungen und administrative Vorlagen für wiederkehrende Aufgaben.
